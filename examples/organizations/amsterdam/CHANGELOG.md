# Changelog — Amsterdam CPRMV / DMN work

Consolidated history for the cell-level legislative-linking design work and the
`HvA_full_dmn_export.dmn` Operaton-evaluation fix, previously split across separate
changelog tables in [`cprmv-spec-proposal-cell-level-granularity.md`](cprmv-spec-proposal-cell-level-granularity.md)
and [`cprmv-cell-level-linking-prototype.md`](cprmv-cell-level-linking-prototype.md).
Both docs, plus [`hva-full-dmn-export-feel-evaluation-fix.md`](hva-full-dmn-export-feel-evaluation-fix.md),
link back here instead of keeping their own tables — see each file's own "Changelog"
section for the pointer.

The DMN fix is backed by a live test suite covering all 25 decisions in the DRD —
[`testCases/test-cases-hva-full-dmn-export.json`](testCases/test-cases-hva-full-dmn-export.json)
(the cases), [`testCases/test-cases-validation-hva.md`](testCases/test-cases-validation-hva.md)
(the reasoning behind each one, plus how to run them yourself), and
[`testCases/test-cases-hva.sh`](testCases/test-cases-hva.sh) (a self-contained runner).

## Executive summary

One pipeline, start to finish:

1. **Legal analysis** — Amsterdam, HvA and PNA Group modeled the regulations in iKnow.
2. **Export to DMN (1st iteration)** — iKnow delivered the full 25-decision DRD,
   `HvA_full_dmn_export.dmn`.
3. **Analysis** — documented in
   [`cprmv-cell-level-linking-prototype.md`](cprmv-cell-level-linking-prototype.md)
   for the iKnow team and
   [`cprmv-spec-proposal-cell-level-granularity.md`](cprmv-spec-proposal-cell-level-granularity.md)
   for the CPRMV spec owner.
4. **Spec owner answers** — open questions resolved; iKnow delivered a new
   export (2nd iteration) of `HvA_full_dmn_export.dmn`.
5. **Further analysis** — the 2nd iteration still had Operaton deploy blockers
   (missing `camunda:historyTimeToLive`, unescaped `&` in `knowledgeSource`
   URLs) and FEEL issues (multi-word bare names, a missing `dmn:output` name
   attribute silently breaking result serialization, malformed `not -` /
   `not(null) -` cells, invalid ranges) — all found and fixed.
6. **Patch** — those fixes landed in `HvA_full_dmn_export-patched.dmn`, the
   single source-of-truth deployment from this point on.
7. **Verification** — a 100-case MC/DC test suite covering all 99 rules across
   all 25 decisions, plus a legal-source cross-check confirming 97 of 99
   `authorityRequirement` links resolve cleanly.
8. **Cell-level legislative grounding** — implemented Layers 1-3 of
   [`cprmv-cell-level-linking-prototype.md`](cprmv-cell-level-linking-prototype.md):
   real `dct:source`/`cprmv:sourceQuote`/`cprmv:isBasedOn` attributes on DMN cells,
   parsed and emitted as SHACL-conformant `cprmv:Rule` resources in the TTL.
9. **LDE validator fixes (Layer 4)** — the `linked-data-explorer` DMN/SHACL
   validator and Operaton-proxy routes fixed to support this DRD's real-world
   shape (namespace handling, date typing, output discovery); documented in that
   repo's own changelog.
10. **Published** — deployed, evaluated, and published as
    [`Digital-Twin-Inkomensregelingen.ttl`](Digital-Twin-Inkomensregelingen.ttl) via
    the CPSV Editor, with zero DMN evaluation issues and zero SHACL validation
    issues.
