# HR Onboarding

## Principles

1. A person is assigned a profile based on characteristics, which is time-bound.
2. There is a profile for a Task / Role / Authority. More than one profile per task is possible.
3. Steps have an associated Task / Role / Authority based on legal requirements and administrative preferences.
4. Elements marked with a '(\*)' have an explicit legal basis
